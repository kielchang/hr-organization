# 介面契約 — R4.3 版本命名 + 變更理由

> 協調者產出。對應 [規劃-改善Roadmap](規劃-改善Roadmap.md) Phase 4 R4.3。
> 為何訪談前做：PM/UXR 都提、低依賴、純加值（不賭 HR 行為假設）。收尾「不賭假設」低風險池的最後一項。
> 狀態：草案 → 開工。最後更新：2026-06-07。

## 0. 目標與非目標

**目標**：發布版本時可填**自訂名稱**與**調整理由**，讓 HR 回顧時知道「這個方案叫什麼、為什麼這樣調」。聚焦**版本層級** metadata（發布時填一次），不是每筆 micro 操作。

**v1 非目標**：
- 不在每筆 ChangeEntry 加 reason（太侵入，且 HR 心智是「這個方案的理由」非「每次點擊的理由」）。
- 不把 R0.1 三題（sponsor/受影響/sustainment owner）持久化——它們維持 R0.1 的 nudge 定位（v1 不存）。R4.3 的 note 是獨立的「調整理由」單一欄位。
- 不碰後端：note 是本機 metadata，雲端寫穿維持只傳 label+data（note 不寫穿，雲端版本無 note——與「JSONB 文件 + best-effort 寫穿」既有取捨一致）。

## 1. 架構決策（ADR）

純前端、版本層級 metadata。沿用既有 PublishedVersion（localStorage）+ DataVersionInfo + 發布流程。後端零改動。

## 2. 型別

### `src/services/publishedVersions.ts`
- `PublishedVersion` 加 `note?: string`（調整理由）。label 已存在。
- `addPublishedVersion(data, label?, effectiveDate?, note?)`：新增 note 參數，created 帶入 note。

### `src/services/dataVersions.ts`
- `DataVersionInfo` 加 `note?: string`。
- `publishedVersionToInfo` 帶入 note（雲端 apiVersionToInfo 無 note，留 undefined）。

## 3. 發布流程

### `src/context/OrgProvider.tsx` — publishVersion 簽章改 options
- 從 `publishVersion(draft, effectiveDate?)` 改為 **`publishVersion(draft, opts?: { label?: string; note?: string; effectiveDate?: string })`**。
- 內部：`addPublishedVersion(draft, opts?.label, opts?.effectiveDate, opts?.note)`。
- 雲端寫穿維持 `apiClient.publishVersion(created.label, created.data)`（note 不傳）。
- **更新所有呼叫端**（OrgChartPage 等）為新簽章。

### `src/components/orgFlow/EditModeToolbar.tsx` — 發布對話框
- `onPublish` 簽章改為帶 options：`onPublish(opts: { label?: string; note?: string; effectiveDate?: string })`。
- 對話框新增（放在生效日**之前**，屬版本主 metadata）：
  - 「**版本名稱**（選填，留空＝以發布時間命名）」Input
  - 「**這次調整的理由**（選填）」Textarea，placeholder 例「強化跨部門協作、整併重疊職能」
- 保留既有生效日與 R0.1 三題（三題仍 nudge、不持久化）。
- 對話框關閉時一併重置 label/note state（比照現有重置三題）。

## 4. 顯示

### `src/components/VersionSelector.tsx`
- 版本下拉 label 已顯示自訂名稱（label 機制不變，自訂名稱自然顯示）。
- 在版本選擇器區塊內，當 `activeVersion.note` 有值時，顯示一行 muted 文字：「**調整理由**：{note}」。

> 其他顯示點（Overview/ChangeLog）v1 不做，保持最小。

## 5. 後端：不涉及

## 7. 向後相容重點

- 既有 PublishedVersion（localStorage 無 note）載入時 note=undefined，顯示時不顯示理由行，不報錯。
