> 協調者產出。使用者 Q2 願景＝離線優先同步；AskUserQuestion 定案先做**最小切片：離線偵測 + 未同步提醒**（不含自動補同步，留待後續切片）。
> 前置：階段 A「進場預設最新雲端版」已完成（commit `a68cf82`）。
> 狀態：開工。最後更新：2026-06-07。

## 0. 範圍邊界（重要）
- **做**：線上/離線偵測、未同步狀態追蹤、畫面提醒 banner。
- **不做（下一切片，本契約明確排除）**：離線期間發布的自動佇列、回線自動 flush/補推、衝突解決、主動輪詢 /api/health。
- 僅在**後端啟用**（`isApiEnabled()`，即 docker 8088）時有意義；dev 5174（無後端）不顯示同步相關提醒。

## 1. 線上狀態偵測
新增 `src/hooks/useOnlineStatus.ts`：
- 初始值 `navigator.onLine`；訂閱 `window` 的 `online`/`offline` 事件更新；卸載時移除監聽。
- 回傳 `isOnline: boolean`。SSR/測試安全（`typeof navigator` 防呆）。
- **不**主動輪詢網路（本切片排除）。

## 2. 未同步狀態追蹤（`OrgProvider`）
- 新增狀態 `cloudSync: { pending: boolean }`（或 `pendingCloudSync: boolean`），透過 OrgContext 對外。
- **設為 pending 的時機**（僅 `isApiEnabled()` 時）：`publishVersion` 內 best-effort 雲端寫入（`apiClient.publishVersion(...)`）`.catch` 失敗時，或發布當下 `!navigator.onLine`：標記 `pending = true`。
- **清除 pending**：`apiClient.publishVersion(...)` `.then` 成功時設 `pending = false`（代表已同步上雲）。
- **持久化**：`pending` 存 localStorage（key 如 `hr-org-cloud-sync-pending`），重整後仍正確反映「有本機變更未上雲」；載入時讀回。
- 後端停用時 `pending` 恆為 false（不顯示）。
- **注意**：本切片只「記錄＋顯示」，不自動重送；使用者要清除可透過下次成功發布。

## 3. 提醒 UI
新增 `src/components/CloudSyncBanner.tsx`，掛在 `src/components/Layout.tsx`（全站可見、置頂內容區上方）：
- 僅 `isApiEnabled()` 時可能顯示；否則 render null。
- 狀態與文案（用既有 `Alert`/設計 token，圖示＋文字、**不只靠顏色**）：
  - `!isOnline`：⚠️「目前離線中——變更僅存在本機，尚未同步到雲端。」
  - `isOnline && pending`：ℹ️「有本機變更尚未同步到雲端。」（本切片不提供自動重送；可不放按鈕，或放一個 disabled/註記「回線同步將於後續版本提供」——擇不誤導使用者者）
  - `isOnline && !pending`：不顯示。
- a11y：容器 `role="status"`、`aria-live="polite"`（非阻斷性通知）；可關閉與否不強制，但若可關閉需鍵盤可達。文案語意清楚、避免工程術語（延續 R0.2 詞彙原則）。
