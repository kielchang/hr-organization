# 介面契約 — R5.3 CSV 欄位中文化

> 協調者產出。對應 [規劃-改善Roadmap](規劃-改善Roadmap.md) Phase 5 R5.3。
> 為何訪談前做：UXR 訪談指南明確點名「CSV 駝峰欄名（employeeNo…）會擋住 HR」。純可讀性、零行為假設賭注、改善訪談 demo 的「載入」體驗。
> 狀態：草案 → 開工。最後更新：2026-06-07。

## 0. 目標與非目標

**目標**：CSV 匯入的欄名改以**中文為主**，HR 看得懂；匯出也用中文 header。**同時向後相容英文欄名**（既有檔案/既有測試不壞）。

**v1 非目標**：不改 CSV 的「一列一筆 assignment」結構；不改 xlsx 解析管線（它重用 matrixToOrgData，header 中英相容後自動受惠）；不做欄位順序自由（仍靠 header 名稱對應，順序本來就無關）。

## 1. 架構決策（ADR）

- 不改 `CSV_MEMBER_COLUMNS`（英文 key，被 type/匯出/UI 多處用）；**新增「欄位 → 中文主名 + 英文別名」的對應表**，header 解析時中英皆認。
- 匯出 header 改用**中文**（HR 友善；匯出→再匯入因雙認所以 OK）。
- 缺欄位錯誤訊息改用**中文欄名**。
- 純前端，後端零改動。

## 2. 欄位中文對應（單一事實來源）

在 `src/services/csvToOrgData.ts` 定義（key＝既有英文 const，zh＝中文主名）：

| 英文 key（不變） | 中文主名（匯出用、範本用） |
|---|---|
| employeeNo | 員工工號 |
| employeeName | 員工姓名 |
| employeeStatus | 在職狀態 |
| groupCode | 組別代碼 |
| groupName | 組別名稱 |
| parentGroupCode | 上層組別代碼 |
| groupStatus | 組別狀態 |
| jobLevelCode | 職級代碼 |
| jobLevelName | 職級名稱 |
| jobLevelRank | 職級層級 |
| supervisorEmployeeNos | 主管工號 |
| primarySupervisorEmployeeNo | 直屬主管工號 |
| isPrimaryGroup | 是否主要組別 |

> 中文欄名**不得含逗號**（避免 CSV 欄位歧義）；說明（如「多筆以 | 分隔」「1/0」）放範本 `#` 註解列，不放欄名。

建議資料結構：
```ts
export interface CsvColumnDef { key: CsvMemberColumn; zh: string; aliases: string[] }
export const CSV_MEMBER_COLUMN_DEFS: CsvColumnDef[]  // 每欄 aliases 至少含英文 key
```

## 3. header 解析（`matrixToOrgData`）

- 改 colIndex 建立邏輯：對每個欄位，在 header（trim 後）依序找「中文主名 → 英文 key → 其他 alias」第一個命中的 index（英文比對 lowercase；中文 trim 即可）。
- 缺欄位錯誤訊息（原 `缺少必要欄位：${missing.join(', ')}`）改列**中文主名**：`缺少必要欄位：員工工號, 員工姓名, …`。
- 其餘解析邏輯（值的解析、parseStatus/parseBoolean 等）完全不動。

## 4. 匯出（`orgDataToCsvMemberRows`）

- header 行從 `CSV_MEMBER_COLUMNS.join(',')` 改為**中文主名** join（依 CSV_MEMBER_COLUMN_DEFS 的 zh，順序與 CSV_MEMBER_COLUMNS 一致）。
- 資料列輸出不變。
- round-trip 保證：匯出（中文 header）→ 匯入（中文認得）→ 結果與原資料一致。

## 5. 範本與範例

- `src/data/templates/org-members.template.csv`：header 改中文；保留 `#` 說明列（補「主管工號多筆以 | 分隔」「是否主要組別填 1/0」「在職狀態 active/inactive 或 在職/停用」等提示）。
- 若 `npm run generate:csv-sample`（scripts/）產生 sample 時引用 CSV_MEMBER_COLUMNS 英文 header → 同步改用中文（讓 sample 也是中文）。前端確認該 script 並改。
- `org-members.sample.csv` 若進版控則一併更新；若 gitignore 則由 script 產生即可。

## 6. UI 文案（`src/pages/CsvImportPage.tsx`）

- 若頁面有列出欄位名稱/說明（英文欄名表），改為中文欄名；若有「下載範本」按鈕指向範本檔，確認範本已中文。
- 匯入錯誤呈現沿用（錯誤訊息已由 service 中文化）。

## 7. 後端：不涉及
