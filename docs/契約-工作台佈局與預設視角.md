# 介面契約 — 工作台佈局優化 + 預設全公司視角

> 協調者產出。使用者驗收 drag-to-reassign 後提出兩個調整。read 現況後定案。
> 狀態：開工。最後更新：2026-06-07。

## 1. 預設全公司視角

**需求**：工作台（/workbench）預設用「全公司視角」（`ALL_GROUPS_VIEW_ID`）開啟，而非預設挑某個組別。

**做法**：WorkbenchPage 初始 groupId 改為 `ALL_GROUPS_VIEW_ID`（不經 `pickDefaultGroupId` 挑組）。
- 範圍：**僅 WorkbenchPage**（它是整合主介面、看整體）。`/org-chart` 維持 `pickDefaultGroupId`（對照頁，不動其行為與既有測試）。
- 注意 reporting + membership 視角都從全公司起；membership 的「全部」即 ALL_GROUPS_VIEW_ID。

## 2. 匯報線佈局直觀化（核心）

**問題**（使用者）：匯報線被其他節點遮蔽，看不出階層關係。例：E008（鄭浩然 L3）的部屬 E009（許文雅 L4）與 E006（黃建國 L5）都匯報 E008，但畫面看不出來。

**根因**（協調者分析 buildOrgFlowGraph.ts）：
- `layoutWithDagre` 用 Dagre TB 算 x（水平排序）與 y（dagre rank）。
- `applyLevelBands` 接著**用 `assignment.level` 覆寫 Y**（topY = level × LEVEL_GAP），但 **X 保留 dagre 的**。
- Dagre 的 rank 來自 edge 結構（最長路徑），**與 `level` 不一致**：例如 E008→E006 是 1 條邊（dagre 視為相鄰 rank），但 level 差 2（L3→L5，跨 L4）。Dagre 依「1 rank 差」排的 X，被 level band 拉成「2 層距」後，水平段落在 L4、穿過 L4 節點；同主管子女也不一定聚在父下方。

**目標**：
1. **同一主管的直接部屬，視覺上聚集在父節點下方**（org chart 標準：父水平置中於其直接子女）——一眼看出 E008 的部屬是 E009、E006。
2. **跨層匯報線的水平段不穿過中間層節點**（落在層與層之間的空隙，RANK_SEP 已留空隙，要讓邊真的走那）。
3. 同層節點不重疊、間距清楚。

**候選手段**（前端評估、選最有效、可組合）：
- **(a) 讓 Dagre 圖結構對齊 level（推薦核心）**：建 dagre 圖時，對「跨層邊」（target.level − source.level > 1）插入 dummy 中繼節點（每中間層一個，source→dummy(L+1)→…→target），讓 Dagre 為跨層邊在中間層保留水平通道、真實節點避讓；**渲染時丟棄 dummy**（不出現在輸出 nodes，edge 仍 source→target）。可搭配把每個真實節點的 dagre rank 對齊其 level（用 dummy chain 自然達成）。
- **(b) 父置中於直接子女**：若 (a) 後父仍未置中，後處理讓父節點 X = 其直接部屬 X 範圍中心（org chart 慣例）。
- **(c) edge 路由微調**：smoothstep 的 `pathOptions`/borderRadius 或 offset，讓隔層邊水平段更明確落在層間。
- 注意：拖曳吸附（levelFromTopY、LEVEL_GAP）、層級輔助線（OrgFlowLevelLines）、drag-to-reassign 都依賴現有 level band 機制——**不可破壞**（拖曳改層級、拖到節點改主管、層線仍要對）。

**驗收**（佈局視覺靠看圖，結構靠測試）：
- 看圖（rebuild docker 後）：E008 的 E009/E006 明顯在其下方、線不被遮、一眼看出階層。
- 結構不變式（QA 可測 buildOrgFlowGraph 純函式）：輸出 nodes **不含 dummy**、同層無 X 重疊、父節點 X 落在其直接子女 X 範圍內（若實作父置中）、edges 數與來源一致、既有層級/拖曳相關不變式不破。

## 3. 角色分派
| 角色 | 範圍 |
|---|---|
| 協調者 | 本契約、看圖整合驗收 |
| 前端 | §1 預設視角 + §2 佈局（buildOrgFlowGraph 為主，必要時 OrgFlowChart edge），不寫測試 |
| 測試/QA | buildOrgFlowGraph 結構不變式測試（無 dummy 外洩、無重疊、父置中若做、edges 正確）；OrgChartPage/orgFlow 既有等價；跑 verify |
| 程式碼審查 | 佈局邏輯正確、不破壞拖曳/層線/drag-to-reassign、無新攻擊面 |
| 文件 | 系統設計文件（佈局說明）、待辦/契約 |

**驗收**：`npm run verify` 綠 + `verify:server` 綠 + rebuild docker 看圖確認階層直觀。**佈局視覺可能需 1-2 輪看圖迭代。**
