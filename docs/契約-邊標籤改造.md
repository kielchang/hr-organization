# 介面契約 — 匯報線標籤改造（透明底·沿線平行，不切斷線）

> 協調者產出。使用者回饋：邊標籤的白底把線「切成兩段」，希望文字沿線平行、不切斷線。
> AskUserQuestion 定案：**保留標籤但改造（透明底·沿線平行）**。
> 繞線引擎改用 ELK 屬另一階段（另立計畫），本契約只改標籤渲染、不動佈局/路由演算法。
> 狀態：開工。最後更新：2026-06-07。

## 1. 現況
- `buildOrgFlowGraph` 產生的 edge 用內建 `type:'smoothstep'` + 頂層 `label`（'主匯報'/'虛線匯報'）+ `labelStyle`。
- React Flow 內建 label 預設帶白色底框，蓋在線上 → 視覺上線被切成兩段。
- `OrgFlowChart` 未註冊任何 `edgeTypes`。

## 2. 目標
- 標籤**透明底**、**浮在線（水平段）上方**、**沿線平行**，線在底下**連續不被切斷**。
- 保留「主匯報 / 虛線匯報」文字與既有線型（實線/虛線）、箭頭、路由（smoothstep + 現有 borderRadius/offset 不變）。

## 3. 做法
新增自訂 edge `src/components/orgFlow/ReportingEdge.tsx`：
- 用 `getSmoothStepPath({ sourceX, sourceY, sourcePosition, targetX, targetY, targetPosition, borderRadius: 12, offset: <現值> })` 取得 `[path, labelX, labelY]`，**與現有路由參數一致**（路由視覺不變）。
- 渲染 `<BaseEdge id={id} path={path} markerEnd={markerEnd} style={...}>`；style 由 `data.isPrimary` 決定：主匯報實線 `strokeWidth:2`、次要虛線 `strokeWidth:1.5, strokeDasharray:'6 4'`（沿用現值）。
- 標籤用 `<EdgeLabelRenderer>` 放一個 `<div>`：
  - 位置 `transform: translate(-50%, -50%) translate(${labelX}px, ${labelY}px) translateY(-10px)`（浮在水平段**上方**約 10px、不壓線）。
  - **無背景**（transparent，不要 labelBg）；`fontSize:10`、`color` 用次級文字色（如 `var(--muted-foreground)` 或既有 token）；`pointerEvents:'none'`、`whiteSpace:'nowrap'`。
  - 文字內容讀 `data.label`。**平行**：本專案 smoothstep 的 label 點落在層間「水平段」，水平文字即與線平行，**不需旋轉**（保持水平）；若 label 點位於垂直段才需 rotate，但組織圖樹邊一律水平段標註，故維持水平即可。
  - `data.label` 為空則不渲染標籤。
- 在 `OrgFlowChart` 註冊 `edgeTypes={{ reporting: ReportingEdge }}`（用 module 常數或 `useMemo` 穩定參考，避免每 render 重建警告）。
- `buildOrgFlowGraph`：edge `type:'smoothstep'` → `type:'reporting'`；把 `label`、`isPrimary`、線型所需資訊放進 `edge.data`（`data.label`、`data.isPrimary`、必要時 `data.offset`）；移除頂層 `label`/`labelStyle`（改由自訂 edge 畫）。**保留 `data.isPrimary`**（centerParents 仍依賴它）。markerEnd 可留在 edge 或移入自訂 edge，擇一一致。

| 程式碼審查 | EdgeLabelRenderer 用法正確、label 不擋互動（pointerEvents none）、edgeTypes 參考穩定、路由視覺與原一致、a11y（裝飾性文字、不只靠顏色——線型+標籤雙重）、無新攻擊面 |

## 5. 驗收
- `npm run verify` 綠 + `verify:server` 綠。
- 看圖（5174/8088）：匯報線**連續不被切**，「主匯報/虛線匯報」文字浮在線上方、與線平行、無白底；線型/箭頭/路由與原相同。
- 拖曳、層級線、drag-to-reassign、centerParents 不受影響。
